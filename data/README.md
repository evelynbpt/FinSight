# Included example data (NOT synthetic)

`macroeconomic_example_REAL.csv` contains 203 real U.S. quarterly macroeconomic observations from `statsmodels.datasets.macrodata` (based on data distributed with Stata). It is included strictly to demonstrate **file upload, data inspection and exploratory plots**. These observations are a **time series**, so the app's random train/test split is inappropriate for evaluating future forecasts. Do not present predictive performance on this file as a valid economic forecast.

For the final classification/regression/clustering **banking use cases**, download a suitable publicly available UCI dataset using the direct source links in `../README.md` and upload it to the app.
